## Project Overview

This project focuses on recognizing human physical activities using sensor data and Machine Learning techniques.

The system uses accelerometer and gyroscope readings to identify different human activities.

## Objectives

- Collect and analyse sensor data.
- Identify different human activities.
- Apply Machine Learning classification.
- Predict activities using a trained model.
- Display model performance.

## Activities Recognized

1. Walking
2. Running
3. Sitting
4. Standing

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Matplotlib

## Machine Learning Algorithm

Random Forest Classifier.

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Run the application:

```bash
streamlit run app.py
```

5. Upload the labelled CSV dataset.

## Dataset Information

The included CSV contains illustrative sample sensor readings for testing the application. It is not real-world measured data.
